- (decision) Feature PRD separate from the product PRD (prd-xrpl-wallet-2026-09-12); references it for shared rules; owner asked for one PRD per feature because the product PRD is ~1,700 lines
- (decision) Offline signing and multi-signing are two features; multi-signing is a later PRD built on this one (owner, 2026-11-07)
- (decision) Three wallet kinds: Online (key, ledger, one network for life), Offline (key, never reads or sends, no network), Transmitter (no key, sends; optional Sync to an address gives a read-only view)
- (decision) Replaces Operating another account (FR-75) and Two-device signing by QR (FR-78)
- (decision) Every submission goes through one shared transmit step; an offline wallet hands the signed transaction out by QR
- (decision) Per-wallet setting Show the signed transaction before sending, default off: shows hash and copy, then Send it to the ledger?
- (decision) Both work splits are built: offline builds and signs (Transmitter only transmits) and Transmitter builds unsigned, offline only signs
- (decision) In the offline-builds way the user builds the whole transaction first; only then the app asks for data to sign (Sequence, fee, LastLedgerSequence, network) from the Transmitter
- (decision) Offline wallet has no network; network comes from the Transmitter and is shown large before signing (owner: it must not have one)
- (decision) Kind is chosen in the create quiz (Online wallet or offline wallet, with consequences) and can be changed per wallet: online to offline (confirm) and offline to online (irreversible-class confirm, network fixed for life)
- (decision) A wallet changed from online to offline carries a permanent was-online mark; an offline passkey-derived key needs a device-bound passkey or shows the synced-passkey warning
- (decision) Consequence texts written in ASD-STE100 from a security view, approved by owner 2026-11-07, copied verbatim
- (assumption) Data to sign reaches the offline device by QR, like today's two-device round
- (event) Fast-path draft written: 19 FRs (OS-FR-1..19), 3 journeys, 4 consequence texts, 5 open questions, 8 assumptions; awaiting owner review
- (decision) Signing window about ten minutes for the Offline-builds round; Tickets stay later work
- (decision) Today's controlled accounts (FR-75) are dropped, not migrated, per FR-95
- (decision) Offline and Transmitter Wallet for the same address on one device: warn, never refuse
- (decision) Synced passkey for an Offline Wallet: warn, never refuse
- (decision) Sync to an address can be changed or removed (owner confirmed)
- (decision) A kept Build lives only while the Wallet is unlocked; lock erases it (owner confirmed)
- (decision) Imported Offline Wallet gets no Was-online mark, but import shows an ASD-STE100 warning to make sure the seed was generated safely (owner, 2026-11-07)
