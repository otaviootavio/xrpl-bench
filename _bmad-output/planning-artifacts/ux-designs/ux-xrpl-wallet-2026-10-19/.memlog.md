- (decision) Home screen is a wallet chooser shown first; one card per wallet; always the chooser on launch (owner).
- (decision) Header control inside a wallet returns to the chooser, like signing out to switch accounts (owner).
- (decision) Create, open, rename, remove live on the chooser. Rename is NEW (no keystore rename today); local to the device, never sent to the ledger (owner).
- (decision) Per-wallet configuration screen holds Edit checks, Reveal seed, Let another wallet sign (control/regular key), Use on another network, Node, two-device signing (owner).
- (decision) Settings keeps app-level items only: Address book, auto-lock, Version/updates, Remove all wallets from this device (owner).
- (decision) Inside a wallet the tabs Balances, Send, Receive, History, Tokens stay; Settings tab becomes app-level (owner).
- (assumption) Constraint AD-26: a locked wallet card shows its name only; Reveal seed and Remove need that wallet's own lock open.
- (decision) Working mode fast path; visual identity inherited from repo DESIGN.md, new components only as delta.
- (decision) Leaving a wallet for the chooser keeps its lock open until auto-lock (owner chose recommended; OQ-2).
- (decision) Wallets sharing a Seed appear as ONE card with a row per network; locked card still shows name only (owner; OQ-3).
- (override) Auto-lock moves from app-level Settings to the per-wallet configuration, because it is per lock in code/PRD FR-65/AD-26 (owner; OQ-1 resolved; supersedes the earlier Settings-keeps-auto-lock line).
- (decision) Per-wallet configuration reachable from a Configure key on each open chooser card AND a Configure key in the in-wallet header (owner; OQ-5).
- (assumption) Remaining OQs (4,6-13) take the draft's recommended defaults pending owner review; Import-from-all-locked-chooser conflict still needs a design answer.
- (decision) Import from the chooser sets its own lock and Open Check, as Generate does; never needs another wallet's lock open (owner; OQ-A resolved). Needs a keystore.ts change: for architecture.
