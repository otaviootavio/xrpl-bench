Change to an offline wallet

  • This wallet stops all connections to the XRP Ledger.
  • This device does not show the balance or history of this wallet after the change.
  • The node setting goes away. The network does not change.
  • The address and the funds do not change.
  • To send a transaction after the change, you must have a Transmitter wallet on a second device.
Caution

WARNING: This change does not make your key safe. The key was on a device that connected to the internet. If malware found the key before the change, the malware still has it. The change cannot remove that risk.

  • To get a key that was never online:
    1. Create a new offline wallet on a device that is disconnected.
    2. Move your funds to the new address, or set the new key as the Regular Key of this account.
    3. If you set a Regular Key, turn off the master key of this account. You must sign this with the old key.
Caution

WARNING: The app cannot make your device offline. Disconnect the device before you sign with this wallet.

Change to an online wallet

  • This wallet connects to the XRP Ledger.
  • The wallet keeps its network. You must select a node.
  • This device shows the balance and history of this wallet.
  • This wallet can sign and send transactions without a second device.
  • Signed transactions that you did not send are still valid until they expire.
Caution

WARNING: The key will be on a device that connects to the internet. Malware or a dangerous browser extension can find it. After this change, the key is not an offline key.

Caution

WARNING: You cannot undo this risk. If you change the wallet back to offline later, the key is still a key that was online. For a large amount, keep this wallet offline.
